# WinSight native tokenizer

ABI v1 is declared in `winsight_tokenizer.h`. Implementation pins official Hugging Face tag `v0.23.3` to commit `301277072263fb3830eb66eec7e47adadf76f1dc`, whose actual Rust crate version is `0.23.2` (not a crates.io0.23.3). Defaults are disabled, `onig` only, no HTTP feature, and Cargo.lock is retained. JSON bytes are supplied by the C# caller after pinned-manifest validation; native code does not choose or download model files. Encoding delegates normalization, added tokens, BOS/EOS and postprocessing to that JSON. No C# tokenizer approximation exists.

The caller owns valid input/output-pointer memory. Returned handles, token-ID slices and UTF8 error strings must each be released once through their matching exported free function. Encoding failure initializes outputs to null/zero and returns 1; Rust panic is caught and returns 2 with an allocated error string. OOM/native pointer misuse is process-fatal, not a successful empty token list. C# wraps the handle in SafeHandle and releases every returned buffer in finally.

Use `scripts/build-native-tokenizer.ps1 -RuntimeIdentifier win-x64`: it performs the offline/locked release Cargo build and emits a source/DLL binding sidecar. The Host build checks the hashes of Cargo.toml, Cargo.lock, lib.rs and DLL; a stale DLL or stale/missing sidecar fails closed, rather than being labeled with the new managed profile. This is an accidental-mix guard, not a signed attestation or same-user sandbox. Source integration was approved by independent manual evidence review; it does not revive the stopped three-failure automated validator. Current dynamic FFI/profile acceptance is recorded separately. Packaging copies the resulting DLL to the host's private `runtimes/win-x64/native/`; P/Invoke loads that exact path, without PATH or system fallback. Build output is ignored, not source-controlled.

The C# embedding profile includes the official tag, exact source commit, actual crate version, ABI1 and special-token contract, so changing this implementation cannot silently reuse an older profile. Existing model weights/schema markers are unchanged; no real index is migrated by this change.

Dependency source-integration review was completed manually after the failed automated validator stopped; the latter remains failed and was not rerun. No reported OSV matches for the pinned source are not a no-vulnerability guarantee; inherited paste1.0.15 is informational-unmaintained. Available license/native/Unicode texts are retained under `licenses/`; full product distribution notices and legal/vulnerability release closure remain separate gates.
