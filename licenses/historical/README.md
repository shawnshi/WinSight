# Historical runtime license records

`swift-LICENSE.txt` is preserved byte-for-byte from the retired Swift packaging chain. This directory records historical attribution; it does not imply that the native payload contains a Swift runtime or that its license inventory has passed release acceptance.

The root LICENSE, NOTICE, DigUp MIT/acknowledgements and `desktop/licenses/` remain in place. Native NuGet, Rust, model and Windows component licenses must still be checked against the actual distribution payload.
